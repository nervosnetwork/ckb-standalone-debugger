# CKB VM Bench

This project is used to bench the performance of ckb-vm when running common cryptographic algorithms.

**Download risc-v program for testing**

```sh
$ wget https://github.com/nervosnetwork/ckb-vm-bench-scripts/releases/download/v0.1.1/binary.tar.gz
$ tar -zxvf binary.tar.gz
```

**Bench**

```sh
$ cargo bench
```
